# Firebird REST Data Service (FRDS)

Firebird REST Data Service (FRDS) — серверное приложение, предоставляющее унифицированный RESTful API для доступа к базам данных Firebird и РЕД База Данных (RedDatabase).  
Проект является учебным прототипом и по своей функциональной направленности выступает аналогом Oracle REST Data Services (ORDS) для экосистемы Firebird.

## Назначение проекта

Традиционно доступ к данным СУБД осуществляется через специализированные клиентские библиотеки и протоколы. В условиях развития микросервисных архитектур и веб-ориентированных решений возникает необходимость предоставления HTTP-доступа к данным базы данных через RESTful API.

FRDS реализует промежуточный серверный слой, который:
- предоставляет доступ к данным и объектам СУБД по протоколу HTTP;
- изолирует клиентские приложения от прямого подключения к базе данных;
- использует метаданные СУБД для универсальной работы с произвольной схемой базы данных.

## Основные возможности

- Получение метаданных базы данных:
  - таблицы и представления;
  - столбцы и их характеристики;
  - первичные ключи;
  - хранимые процедуры и их параметры;
- Доступ к данным таблиц через RESTful API;
- Вызов хранимых процедур и функций базы данных;
- Использование метаданных Firebird для динамической работы с объектами БД;
- HTTP Basic аутентификация для защищённых ресурсов;
- Поддержка CORS для работы с веб-клиентами;
- Автоматическое документирование RESTful API с использованием OpenAPI;
- Пользовательский интерфейс Swagger UI для тестирования API.

## Технологический стек

- Java 17
- Spring Boot

- Spring Security
- Spring JDBC
- Spring Cache
- Firebird JDBC Driver
- springdoc-openapi (OpenAPI / Swagger UI)
- Firebird / РЕД База Данных
- Linux (Red OS)

## Конфигурация подключения к базе данных

Приложение рассчитано на работу с **одной базой данных на одну инсталляцию сервиса**.  
Параметры подключения задаются через `application.yml` и поддерживают использование переменных окружения:

```yaml
spring:
  datasource:
    url: jdbc:firebirdsql://${DB_HOST:localhost}:${DB_PORT:3050}/${DB_PATH:employee}?charSet=utf-8
    username: ${DB_USERNAME:SYSDBA}
    password: ${DB_PASSWORD:masterkey}
    driver-class-name: org.firebirdsql.jdbc.FBDriver
